# صندوق — Sanduq

تطبيق ويب لتتبّع الدخل والمصروفات الشخصية، مبني بـ **Laravel 12** و **Blade**.

يتيح التطبيق تسجيل العمليات المالية وتصنيفها ضمن فئات، ثم عرض ملخّصات وتقارير
مالية حسب الفترة الزمنية والفئة. الواجهة عربية بالكامل مع دعم الإنجليزية،
وتعمل على الحاسوب والتابلت والجوال.

> مبني وفق وثيقة المتطلبات `SRS_Sanduq` — الإصدار 1.0

---

## المزايا

- **حساب مستخدم كامل** — تسجيل، دخول، خروج، واستعادة كلمة المرور
- **عمليات مالية** — إضافة وتعديل وحذف عمليات الدخل والمصروف
- **تصنيفات** — فئات خاصة بكل مستخدم، لكل فئة نوع (دخل / مصروف) وأيقونة
- **لوحة تحكم** — إجمالي الدخل والمصروف والرصيد الصافي
- **تقارير** — فلترة حسب الفترة الزمنية والفئة، مع رسم بياني شهري
- **عربي / إنجليزي** — تبديل فوري للغة مع انقلاب اتجاه الواجهة (RTL ⇄ LTR)
- **وضع فاتح / داكن** — يُحفظ اختيار المستخدم في المتصفح
- **تصميم متجاوب** — شريط جانبي على الشاشات الكبيرة، وشريط سفلي على الجوال

## التشغيل محليًا

### المتطلبات

- PHP **8.2** فأعلى
- Composer
- MySQL أو MariaDB (مثلًا عبر XAMPP)

### الخطوات

**1. استنساخ المشروع وتنصيب الحزم**

```bash
git clone https://github.com/vartolo007/sanduq.git
cd sanduq
composer install
```

**2. تجهيز ملف الإعدادات**

```bash
cp .env.example .env
php artisan key:generate
```

**3. إنشاء قاعدة البيانات**

```sql
CREATE DATABASE sanduq CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

ثم عدّل بيانات الاتصال في `.env` إن لزم:

```env
DB_CONNECTION=mysql
DB_DATABASE=sanduq
DB_USERNAME=root
DB_PASSWORD=
```

> الترميز `utf8mb4` ضروري لتخزين النصوص العربية بشكل صحيح.

**4. تنفيذ الترحيلات وتشغيل الخادم**

```bash
php artisan migrate
php artisan serve
```

التطبيق يعمل الآن على <http://127.0.0.1:8000>

## بنية المشروع

```
app/
  Http/
    Controllers/Auth/     كنترولرات المصادقة
    Middleware/           SetLocale — يضبط اللغة من الجلسة
    Requests/Auth/        قواعد التحقق من المدخلات
  Models/                 نماذج Eloquent
lang/
  ar/  en/                ملفات الترجمة
public/
  css/  js/               التنسيقات وسكربتات الواجهة
resources/views/
  components/             مكوّنات Blade القابلة لإعادة الاستخدام
  components/layouts/     قوالب الصفحات
routes/
  web.php                 مسارات التطبيق
  auth.php                مسارات المصادقة
```

## ملاحظات

- **البريد الإلكتروني:** الإعداد الافتراضي `MAIL_MAILER=log`، أي أن رسائل استعادة
  كلمة المرور تُكتب في `storage/logs/laravel.log` بدل إرسالها فعليًا. للاستخدام
  الحقيقي اضبط خادم بريد في `.env`.
- **Vite و Tailwind** موجودان ضمن حزم المشروع لكنهما غير مستخدمَين — التنسيق كله
  ملفات CSS ثابتة في `public/css`.
