# صندوق — Sanduq

تطبيق ويب لتتبّع الدخل والمصروفات الشخصية، مبني وفق وثيقة المتطلبات (SRS).

يتيح للمستخدم تسجيل عملياته المالية وتصنيفها، وعرض ملخّصات وتقارير مفلترة
حسب الفترة الزمنية والتصنيف، مع رسم بياني للدخل والمصروف.

**التقنيات:** Laravel 12 · PHP 8.2+ · MySQL · Blade · واجهة عربية/إنجليزية
مع دعم RTL ووضع فاتح/داكن.

---

## التشغيل

### المتطلبات
- PHP 8.2 أو أحدث
- Composer
- MySQL

> لا حاجة إلى Node.js أو npm: ملفات CSS و JavaScript جاهزة في `public/`
> ولا تمرّ بخطوة بناء.

### الخطوات

**1. تثبيت الحزم**

```bash
composer install
```

**2. إنشاء ملف الإعدادات**

```bash
cp .env.example .env
```

على Windows (PowerShell): `Copy-Item .env.example .env`

**3. ضبط قاعدة البيانات**

أنشئ قاعدة بيانات فارغة:

```sql
CREATE DATABASE sanduq CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

ثم عدّل في `.env` بيانات اتصالك — غالبًا يكفي ضبط `DB_PASSWORD`:

```
DB_DATABASE=sanduq
DB_USERNAME=root
DB_PASSWORD=كلمة_مرور_MySQL_عندك
```

**4. توليد مفتاح التطبيق**

```bash
php artisan key:generate
```

**5. إنشاء الجداول**

```bash
php artisan migrate
```

**6. بيانات تجريبية — اختياري ومُستحسن للمراجعة**

```bash
php artisan db:seed
```

يُنشئ حسابًا جاهزًا ببيانات موزّعة على ثمانية أشهر، فتظهر اللوحة والتقارير
والرسم البياني مليئة من أول تشغيل بدل صفحات فارغة:

| البريد | كلمة المرور |
|---|---|
| `demo@sanduq.test` | `password` |

> حساب للمعاينة المحلية فقط. تشغيل الأمر مرة ثانية لا يضاعف البيانات.

**7. التشغيل**

```bash
php artisan serve
```

ثم افتح <http://localhost:8000>. سجّل الدخول بالحساب التجريبي أعلاه، أو أنشئ
حسابك من صفحة "إنشاء حساب" — ويبدأ كل حساب جديد بأحد عشر تصنيفًا افتراضيًا
(راتب، طعام، مواصلات…) حتى لا تكون الصفحة الأولى فارغة.

## تجربة استعادة كلمة المرور

الاستعادة تتم برمز من **٦ خانات** يُرسل إلى البريد، لا برابط.

بالإعداد الافتراضي (`MAIL_MAILER=log`) **لا يُرسل بريد فعليًا**، بل تُكتب
الرسالة كاملةً في السجل — وهذا كافٍ لتجربة التدفق كاملًا:

1. من صفحة الدخول اضغط "نسيت كلمة المرور؟" وأدخل بريد حسابك.
2. استخرج الرمز من السجل:

```bash
grep -oE '[0-9]{6}' storage/logs/laravel.log | tail -1
```

على Windows (PowerShell):

```powershell
Select-String -Path storage/logs/laravel.log -Pattern '\b\d{6}\b' | Select-Object -Last 1
```

3. أدخل الرمز وكلمة المرور الجديدة في الصفحة التالية.

لإرسال بريد حقيقي بدل السجل، اتبع التعليمات في `.env.example` تحت قسم البريد.

### قيود الأمان في الرمز

الرمز قصير (مليون احتمال)، فلا يقوم أمانه على طوله بل على قيود مجتمعة:

| القيد | القيمة |
|---|---|
| مدة الصلاحية | ١٠ دقائق |
| المحاولات الخاطئة | ٥ ثم إغلاق ١٥ دقيقة |
| الفاصل بين إرسالين | ٦٠ ثانية |
| الاستخدام | مرة واحدة فقط |
| التخزين | مجزّأ (hashed) لا نصًا صريحًا |

ولا تكشف الصفحة ما إذا كان البريد مسجّلًا أم لا، فلا تُستخدم لاستكشاف
حسابات النظام.

## بنية المشروع

| المسار | المحتوى |
|---|---|
| `app/Http/Controllers` | الكنترولرات (حركات، تصنيفات، تقارير، لوحة التحكم) |
| `app/Http/Requests` | قواعد التحقق من المدخلات |
| `app/Support` | منطق مساعد: حساب الفترات والإحصاءات ورمز الاستعادة |
| `app/Policies` | صلاحيات الوصول — كل مستخدم يرى بياناته فقط |
| `resources/views` | قوالب Blade ومكوّناتها |
| `lang/ar`, `lang/en` | نصوص الواجهة باللغتين |

### ملاحظات على التصميم

- **لا يُخزَّن رصيد جاهز:** كل الإجماليات تُحسب من جدول `transactions` عند
  كل طلب، عبر `SUM` و `GROUP BY` داخل قاعدة البيانات لا في PHP.
- **عزل البيانات:** كل استعلام يبدأ من `$user->transactions()` فيُضاف شرط
  المستخدم تلقائيًا ولا يمكن نسيانه.
- **اسمان لكل تصنيف** (`name_ar` و `name_en`) ليتبع التصنيف لغة الواجهة عند
  التبديل بينهما.

## ملف `.env`

غير موجود في المستودع عمدًا: يحتوي إعدادات خاصة بكل جهاز (كلمة مرور قاعدة
البيانات، مفتاح التطبيق، بيانات البريد). انسخ `.env.example` واضبط قيمك
كما في خطوات التشغيل أعلاه.

## الرفع على السيرفر

### 1. الملفات

```bash
git clone https://github.com/vartolo007/Sanduq.git
cd Sanduq
composer install --no-dev --optimize-autoloader
```

`vendor/` غير مرفوع في المستودع، فلا بد من `composer install` على السيرفر.

### 2. مجلد الجذر — مهم

الوضع الصحيح أن يشير النطاق (أو الـ subdomain) إلى مجلد **`public` وحده**.

إذا تعذّر ذلك على الاستضافة ووُضع المشروع كاملًا داخل مجلد يُفتح عبر
`.../اسم-المجلد/public`، فإن كل ما بجانب `public` يصبح قابلًا للتنزيل من
المتصفح — وفي مقدّمته `.env` بكلمة مرور قاعدة البيانات ومفتاح التطبيق.
ملف `.htaccess` في جذر المشروع يغلق ذلك، لكنه لا يعمل إن كانت الاستضافة
تتجاهل ملفات `.htaccess` (`AllowOverride None`).

### 3. الإعدادات

```bash
cp .env.example .env
php artisan key:generate
```

ثم في `.env`:

| المفتاح | القيمة على السيرفر |
| --- | --- |
| `APP_ENV` | `production` |
| `APP_DEBUG` | `false` — وإلا ظهرت تفاصيل الأخطاء والمسارات للزوار |
| `APP_URL` | العنوان الكامل كما يُفتح في المتصفح |
| `APP_TIMEZONE` | `Asia/Damascus` |
| `DB_*` | بيانات قاعدة البيانات على السيرفر |
| `MAIL_*` | إعدادات SMTP — إن بقيت `MAIL_MAILER=log` فلن تصل رموز استعادة كلمة المرور |

### 4. قاعدة البيانات والصلاحيات

```bash
php artisan migrate --force
chmod -R 775 storage bootstrap/cache
```

### 5. بعد كل تحديث

```bash
git pull
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan optimize:clear
```

`optimize:clear` ضروري: بدونه قد يبقى Laravel يقرأ إعدادات أو قوالب مخزّنة
من نسخة سابقة.

### متطلبات السيرفر

PHP **8.2** فأعلى، وMySQL أو MariaDB، مع الامتدادات التي يطلبها Laravel 12
(`pdo_mysql`, `mbstring`, `openssl`, `tokenizer`, `xml`, `ctype`, `json`).
